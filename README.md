A token launch radar: it reads a sealed DefiLlama snapshot, ranks the protocols that record no token by what their launch would be worth, and shows a reader how to farm each one. The implied value comes from the protocol's own TVL, its seven-day growth and how long it has run without a token, never from a list of names.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
